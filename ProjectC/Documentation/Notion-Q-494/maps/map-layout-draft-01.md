## 지도와 시작 배치

좌하단이 원점이며 128×128 격자입니다. 생산지역은 `y=0..102`, 전투지역은 `y=103..127`입니다. 시설 좌표는 점유 사각형의 좌하단 칸입니다.

| 대상 | 좌표 | 크기 | 비고 |
| --- | --- | --- | --- |
| 항구 | (61, 2) | 6×4 | 생산지역 아래쪽 중앙, 외부 선박 출구 개방 |
| 철판 설비 | (58, 52) | 2×2 | 시작 시설, 컨베이어 미연결 |
| 탄약 공장 | (66, 52) | 3×3 | 시작 시설, 컨베이어 미연결 |
| 전초기지 | (62, 101) | 4×4 | 생산/전투 경계 중앙, 고정 시설 |
| 시작 터렛 | (64, 109) | 1×1 | 제안 시작 위치, 초기 탄약 0 |
| 원석 지점 | (20, 25), (105, 57), (25, 87) | 지점 | 채취시설은 시작 지급 없음 |
| 서쪽 진입 | (0, 114) | 지점 | 전투지역 경계에서 실제 생성 |
| 북쪽 진입 | (64, 127) | 지점 | 전투지역 경계에서 실제 생성 |
| 동쪽 진입 | (127, 114) | 지점 | 전투지역 경계에서 실제 생성 |

## 산 영역

원문은 지도 외곽 2칸에 산을 놓고 항구 출구와 세 진입 위치를 엽니다. 전투지역 내부 산은 아래 사각형 후보로 제시하며, 사격 차폐와 병목 검증용 초기값으로 채택했습니다.

| 종류 | 칸 좌표 범위 | 크기 |
| --- | --- | --- |
| 내부 북서 | x=34..47, y=113..120 | 14×8 |
| 내부 북동 | x=80..93, y=113..120 | 14×8 |
| 내부 남서 | x=17..24, y=104..108 | 8×5 |
| 내부 남동 | x=103..110, y=104..108 | 8×5 |

외곽 개방 폭은 원문 이미지에 그려진 통로를 따른 초기 블록아웃 값입니다. 전투 진입은 지도 밖에서 접근하는 시각 연출과 분리하며, 실제 적은 지정한 경계 진입점에서 생성합니다. 구체 추적 경로를 고정 레일로 강제하지 않습니다.

## 규칙 연결

- 산은 지상 적의 이동, 시설 배치, 직사 사격을 막습니다. 제거할 수 없습니다.
- 드론은 지도 안의 산을 직선 비행으로 통과할 수 있습니다.
- 적은 0.5×0.5칸의 연속 좌표로 이동하고, 서로 겹치지 않습니다. 경로를 막는 시설은 공격 대상으로 삼습니다.
- 문서의 통로 연결 검사는 실제 군집, 전투, 밸런스, 성능 검증을 대체하지 않습니다.
