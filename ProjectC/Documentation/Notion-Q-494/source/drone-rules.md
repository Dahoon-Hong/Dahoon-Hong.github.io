# Project C 드론 배정 명세 — Q-424 기준

- 근거: [planning.md](planning.md)의 GR-420~424와 기존 드론 우선순위·창고·회수·구역 배분 규칙.
- 연속 질의2/10묶음의 답변을 반영했습니다. 진행·중단 상태는 [question-cycle.md](question-cycle.md)에서 관리합니다. 2026-10-28에3/10묶음부터 질의를 재개했습니다.
- 엔진 공통 명세입니다. 배정 알고리즘의 성능·게임 밸런스·자동 테스트 실행 결과는 아닙니다.

## 적용 규칙

| 항목 | 처리 |
| --- | --- |
| 운반 우선순위 | 도착지 시설의1~5 설정,5가 최고·미설정3 |
| 현장 건설·수리·철거 우선순위 | 대상 시설의 같은1~5 설정 사용(GR-422) |
| 같은 우선순위 | 먼저 생성된 실행 가능한 작업 우선 |
| 생성 시각까지 동률 | 드론에서 작업 시작 위치가 가까운 작업 우선(GR-420) |
| 같은 작업의 유휴 드론 선택 | 같은 구역의 수행 가능한 드론 중 시작 위치에 가장 가까운 드론(GR-423) |
| 자재 대기 후 재시도 | 취소되지 않은 작업은 원래 생성 순서 유지(GR-421) |
| 우선순위 설정 변경 | 현재 작업은 유지, 다음 신규 배정부터 반영 |
| 유휴 드론 복귀 중 새 작업 | 전초기지 도착 전에도 현재 소속 구역의 새 작업 배정 가능 |
| 구역 변경 대기 | 현재 작업을 마친 뒤 전초기지에서 소속 변경 |
| 드론 간 이동 | 겹쳐 통과 가능, 서로 이동을 막거나 회피하지 않음(GR-424) |

## 배정 알고리즘 연결안

1. 작업의 대상·자재·실제 수행 가능 상태와 드론의 소속·유휴 여부를 확인합니다. 지금 실행할 수 없는 요청은 남겨두되 실행 가능한 작업을 막지 않도록 합니다.
2. 실행 가능한 작업을 유효 우선순위 내림차순, 원래 생성 시각 오름차순으로 비교합니다.
3. 이 두 조건까지 같은 최상위 후보에서는 가능한 작업/드론 조합의 시작 위치 거리를 비교하는 설계안입니다. 해당 작업에 가까운 드론과 해당 드론에 가까운 작업 규칙을 함께 적용합니다.
4. 모든 비교 조건까지 같으면 안정적인 작업·드론 식별 순서로 최종 결정하는 기술설계안입니다. 무작위 변경으로 담당이 계속 바뀌지 않도록 합니다.
5. 한 건의 배정을 확정할 때 실제 가용 자재·다른 예약을 확인하고 중복 예약·중복 담당 배정을 막습니다. 다음 배정은 반영된 상태로 판단합니다.

- 시작 위치는 운반 작업의 픽업 지점, 현장 작업의 대상 시설입니다. 드론의 기존 직선 비행과 일치하는 거리 계산을 사용하되 구체 시설 접근점은 기술설계에서 정합니다.
- 기존 작업이 취소되지 않았다면 잠시 자재가 없다는 이유로 생성 시각을 계속 갱신하지 않습니다. 취소 후 새로 만든 작업은 새 작업으로 취급합니다.
- 물자 부족·목적지 공간·소속 구역 제약을 거리 규칙으로 우회하지 않습니다. 가까운 드론이라는 이유로 수행 중 작업을 빼앗지 않습니다.
- 드론이 겹칠 수 있어도 동일 시설 현장 작업자 제한은 유지합니다. 건설/수리/철거 각각의 기존 동시 작업자 수와 시간 규칙을 이동 충돌 규칙으로 바꾸지 않습니다.
- 공급원 선택과 회수 목적지 선택의 기존 차이를 유지합니다. 전초기지 보충 공급원은 가까운 가용 공급원 우선이고, 회수 목적지는 수용 가능한 창고의 우선순위부터 비교합니다.

| --- | --- | --- |

| DR-02 | 우선순위는 같고 생성 시각이 다름 | 먼저 생성된 실행 가능한 작업 우선 |
| DR-03 | 우선순위·생성 시각까지 같고 시작 위치 거리가 다름 | 가까운 작업부터 배정 |
| DR-04 | 자재 부족으로 대기한 오래된 요청이 다시 실행 가능해짐 | 원래 생성 순서를 유지해 동순위 후보와 비교 |
| DR-05 | 같은 작업의 같은 구역 유휴 드론2대, 거리 다름 | 시작 위치에 가까운 드론 배정 |

| DR-07 | 드론 여러 대가 같은 위치를 통과 | 상호 충돌·회피 대기 없음, 물자·작업 상태는 각각 유지 |
