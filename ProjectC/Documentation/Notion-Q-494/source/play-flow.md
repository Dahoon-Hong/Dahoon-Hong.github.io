## 시작 조건과 확정 시간표

수출 승리는 실제 선박 출발이3900게임 초 미만일 때만 인정합니다(GR-415). 정확히3900초에 목표를 달성하는 출발은 늦은 것으로 판정합니다.

모든 시간은 게임 시간입니다. 플레이어가 멈추면 시간표도 멈추며, 메뉴와 안내는 자동으로 시간을 멈추지 않습니다.

| 시점 | 확정 사건 | 준비 흐름에서 확인할 내용 |
| --- | --- | --- |
| 0초 | 첫 정기선 철100개 주문 확정·자금100 선결제, 첫 선박 도착 | 자금500→400. 철은 실제 하역된 만큼만 사용 가능. 시작 재고와 벨트 연결은 없음 |
| 첫 하역 | 철100개를 20개/초로 순차 반입 | 대기·중단 없이 전량 하역하면 순수 하역5초. 철이 일반 창고나 공장에 순간 생성되지 않음 |
| 120초 | 180초 도착 예정 정기 항차 주문 확정·선결제 | 기본 계약 유지 시 철100개. 계약 수정은 적용 버튼을 눌러야 하며 확정 항차는 변경 불가 |
| 180초 | 첫 지원금 지급·다음 정기선 예정 도착 | 수출 실적이 없으면 지원금100. 실제 접안·하역은 접안 상황에 따름 |
| 270초 | 첫 웨이브30초 전 진입점 강조 | 화면으로만 알림. 탄약 실제 보유량·전초기지 중계·터렛 사거리를 확인 |
| 300초 | 첫 웨이브10기 시작·360초 항차 주문 확정 시점 | 준비 완료 여부와 무관하게 진행. 첫 전투와 다음 항차 결제를 함께 확인 |

- 계약 변경·단발주문·드론 구매·수출·환불이 없는 기본 자금 예시는 0초400→120초300→180초400→300초300입니다. 향후 실제 주문이 있으면 이 예시를 그대로 사용하지 않습니다.
- 300초는 첫 적 등장 시점이며 적이 전초기지에 도착하는 시점과 다릅니다. 지도상의 실제 이동과 차폐는 따로 검증합니다.

## 첫 플레이 안내와 준비 순서

기존 네 단계 안내를 유지합니다. 첫 세 단계의 상세 감지 조건은 아래와 같이 제안하며, 마지막 단계의 탄약1개 실제 도착 조건은 GR-370 확정 사항입니다. 안내는 목표 패널과 대상 강조로 제공하고 건설·목표 설정·운반을 대신 실행하지 않습니다.

| 단계 | 플레이어가 확인·조작할 내용 | 다음 단계로 넘어가는 조건 |
| --- | --- | --- |
| 1. 철 반출 | 항구의 실제 하역 철과 초기 철판 설비를 확인. 드론 자동 원료 보충 또는 직접 건설한 벨트로 공급 | 제안: 항구 철이 실제 반출되어 초기 철판 설비 입력에1개 이상 도착 |
| 2. 철판 생산 | 초기 철판 설비가 철1개를 소비해1초 동안 생산하는 흐름 확인 | 제안: 철판1개 이상 실제 생산 완료 |
| 3. 탄약 생산 | 초기 탄약 공장에 철판 공급. 철판1개당12초 후 탄약12개 생산 | 제안: 첫 탄약 묶음의 실제 생산 완료 |
| 4. 터렛 보급 | 전초기지의 탄약 보충 목표를 올린 뒤 적용 버튼을 눌러 생산측에서 반입하도록 설정. 전투측 드론이 전초기지에서 터렛으로 운반하는 과정 확인 | 확정: 터렛에 탄약1개 이상 실제 도착 |

- 초기 드론5대는 생산4대·전투1대입니다. 시작부터 벨트가 필수라는 안내를 만들지 않습니다. 드론의 자동 수요 보충을 활용할 수 있습니다.
- 전초기지의 품목별 드론 보충 목표 기본값은0입니다. 드론 중계로 탄약을 보내려면 탄약 목표를 올리고 적용 버튼을 눌러야 합니다. 벨트 반입은 이 목표값으로 제한하지 않습니다.
- 생산지역에서 전투지역으로 가는 탄약은 반드시 전초기지에 실제 입고된 뒤 반출합니다. 공장에서 터렛으로 바로 넘어가는 안내를 만들지 않습니다.
- 안내 완료는 첫 보급을 배운 상태입니다. 첫 웨이브를 버틸 탄약을 충분히 확보했다는 판정과 구분합니다.
- 첫 플레이 안내를 완료하거나 건너뛴 뒤 새 판에서는 자동 표시하지 않습니다. 메뉴에서 다시 켤 수 있습니다. 메뉴를 여는 동안에도 기존 배속·정지 상태를 유지합니다.

## 초기 철 배분과 첫 방어의 검토 기준

| 계산 예시 | 필요량 | 해석 |
| --- | --- | --- |
| 적1기 처치 | HP100 ÷ 터렛 피해20 = 5발 | 다른 피해가 없고 유효 사격이 이루어지는 경우 |
| 첫 웨이브10기 처치 | 10×5 = 50발 | 사거리·표적 분산·적 접근 시간 때문에 생기는 방어 문제를 해결해 주는 수치는 아님 |
| 탄약5회 생산 | 철판5개→탄약60개, 순수 생산60초 | 기존 철판 설비로 철5개가 필요. 시설·운반 대기와 전초기지 중계는 별도 |
| 채취2기+정제2기 건설 | 철80개+철판20개 | 철판 원료까지 포함하면 철100개분. 드론 운반·현장 건설 시간은 별도 |
| 위 확장과 탄약60개 생산 | 철105개분 | 기존 지급 설비를 유지하고 철거 환급을 사용하지 않는 예시. 벨트·추가 터렛·창고·수리 비용은 포함하지 않음 |

- 첫 철100개 전량을 수출 설비 확장에 배분하면 이 예시의 방어 탄약 원료가 부족합니다. 방어 원료를 남기고 후속 정기 수입이나 단발 수입을 연결하는 흐름을 검증합니다.
- 이 계산은 자원 사용량 예시입니다. 공장 입력 자동 보충·출력 재고·운반 중 물자 때문에 실제 특정 시점의 재고는 달라질 수 있습니다. 목표 재고나 자동 생산 상한을 새로 지정하지 않습니다.
- 초기 터렛1기의 보관량60발만으로 첫 웨이브의 수량상 수요50발을 충족할 수 있습니다. 한 터렛으로 실제 첫 방어가 성공한다는 보장은 없으며 세 진입점·산 차폐·사거리8·동시 접근을 검증해야 합니다.
- 일시정지 중 벨트 방향 글자·화살표는 표시하지 않습니다. 방향 확인을 이유로 새 보조 표시를 넣지 않습니다.

## 수출로 확장하는 흐름

1. 초기 탄약 공급을 유지하면서 원석 지점에 채취 시설과 정제 시설을 건설합니다. 건설 자재도 실제 운반·현장 작업을 거칩니다.
2. 채취 출력 원석을 정제 입력에 공급하고, 완성 결정을 항구의 수출 재고까지 실제 운반합니다. 드론을 이용하는 경우 목적지 보충 목표와 기존 수요 규칙을 확인합니다.
3. 기본 결정 정기 수출 계약500개를 확인합니다. 준비량이 적어도 실제 준비량만 부분 수출할 수 있으므로 첫 수출을 위해 반드시500개가 모일 필요는 없습니다.
4. 선적 시작 때 확정한 결정 수량을 실제로 싣고 선박이 출발하면 수출 실적과 결정당 자금2를 반영합니다. 선적 도중 들어온 결정은 이번 확정 선적량에 추가하지 않습니다.
5. 실제 출발로 인정된 누적 수출량에 따라 다음 정기 지원금이 증가합니다. 수입·드론·탄약·방어 시설 증설 비용을 함께 확인합니다.
6. 최소2개의 채취 시설과2개의 정제 시설을 활용하는 흐름을 검토합니다. 추가 시설·드론·벨트의 효율은 실제 거리와 물류 부하를 확인한 뒤 판단합니다.

### 생산량이 뜻하는 최소 조건

- 정제 시설1기는 0초부터3900초 내내 가동해도 결정1950개가 상한이므로 승리 목표2000개에 미달합니다.
- 채취 시설1기도 같은 기간 원석3900개가 상한입니다. 결정2000개에는 원석4000개가 필요하므로 초기 원석0인 현 규칙에서는 채취 시설도 최소2기가 필요합니다.
- 위 최소 조건은 철거·재건설을 하더라도 한 시설분의 처리량만으로는 부족하다는 뜻입니다. 각 시설을 반드시 같은 시점에2기씩 완공해야 한다는 새 규칙은 아닙니다.
- 채취2기·정제2기가 동시에 쉬지 않고 공급·가동하면 결정 합계1개/게임 초입니다. 결정2000개에는 순수 가동2000초가 필요하며 초기 가동 지연·중단·운반·선적·실제 출발 시간이 추가됩니다. 이 네 시설만으로 승리가 보장되지는 않습니다.

## 구현에서 확인할 연결 조건

| 검증 상황 | 확인할 동작 |
| --- | --- |
| 초기 시설·드론만 사용하는 준비 | 철 반출→철판→탄약→전초기지→터렛이 새 초기 물자 없이 이어지는지, 실제 첫 보급 시각 기록 |
| 첫 웨이브 준비 | 270초 강조와300초 등장, 세 진입점 접근, 유효 사격·소모 탄약·전초기지 피해를 기록 |
| 수출 확장 | 건설에 배분한 철판과 탄약 원료가 경쟁하는 상황, 원석 공급·항구 수출 재고·출발 정산 연결 |
| 선박 대기 | 대기 순번이 기존 도착순 규칙과 일치하고 기다린 시간이 게임 배속·정지를 따르는지 |
| 안내 완료·건너뛰기 후 새 판 | 자동 안내가 뜨지 않고 메뉴에서 다시 켤 수 있는지 |
| 적용 전 창 닫기 | 언어·정기 계약의 편집값만 폐기되고 즉시 반영한 음량·효과는 유지되는지 |
| 프로그램 재실행 | 적용한 사용자 설정 유지, 진행 중 판을 복구하는 기능은 제공하지 않음 |

안내 단계의 감지 조건, 목표 재고 입력 위치, 화면별 상태 전이를 [화면 흐름 명세](ui-flow.md)에 연결했습니다. Q-410~414 답변을 반영해 안내 재개·배속 선택·목표 적용·대상 전환·빈 필터 처리를 연결했습니다. 생산·물류·방어 시간은 구현 후 기록하며 엔진 선택은 제약조건이 구체화될 때 다시 판단합니다.

## 압박 곡선의 검증 기준 — GR-438에서 도출

- 초반: 실제 반입→생산→전초기지 중계→터렛 보급을 배우고 첫 방어를 준비할 수 있는지 확인합니다.
- 중반: 방어 보급을 유지하면서 채취·정제·수출을 증설해야 하는 판단이 생기는지 확인합니다.
- 후반: 이미 구축한 공급망의 지속성·수송 병목·수리/증설 판단을 시험하는 압박이 생기는지 확인합니다.
- 위 기준은 단계별 새 시간 경계나 난이도 수치를 지정하지 않습니다. 기존300초 첫 웨이브·120초 간격·3900초 미만 수출 출발과 초기값을 유지하고 검증 자료로 평가합니다.
