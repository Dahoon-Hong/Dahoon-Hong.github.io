## 수치·시간표 검산

| 항목 | 계산 | 의미 |
| --- | --- | --- |
| 마지막 웨이브 시작 | 300 + 120×29 = 3,780게임 초 | 63분에30회차 시작 |
| 최종 기한 | 3,780 + 120 = 3,900게임 초 | 65분. 일정한4배속·정지 없음이면 실제16분15초 |
| 정제 시설1기 최대 생산량 상한 | 결정1개/2초 × 3,900초 = 1,950개 | 0초부터 쉬지 않고 정제해도2,000개 미달. 목표 달성에는 정제 시설 최소2기가 필요. 실제 운반·가동 지연·출발 정산까지 고려하면 더 여유가 필요함 |
| 채취 시설1기 최대 공급량 상한 | 원석1개/초 × 3,900초 = 3,900개 | 결정2,000개에는 원석4,000개가 필요하므로 초기 원석0인 현 규칙에서 채취 시설도 최소2기가 필요 |
| 30웨이브 전체 적 수 | 30×(10+155)/2 = 2,475기 | 전체 등장 가능 수이며 승리에 반드시 전부 처치해야 한다는 새 조건은 아님 |
| 전체 적 처치의 이상적 탄약 수요 | 2,475×(100/20) = 12,375발 | 적HP100·터렛 피해20·다른 피해 없음의 전원 처치 계산. 조기 수출 승리의 필수 탄약 수량으로 사용하지 않음 |
| 탄약 공장1기 이상적 생산량 | 12발/12초 × 3,900초 = 3,900발 | 전30웨이브 전원 처치 시나리오에는 추가 생산 설비가 필요. 실제 필수 공장/터렛 수는 가동 시점·배치·승리 시점에 따라 플레이 검증 필요 |
| 정기선 최대 철 하역+결정 선적 시간 | 500/20 + 500/20 = 50게임 초 | 자재가 준비되고 인계가 막히지 않은 순수 처리시간은 접안 상한60초 안. 실제 대기·재고 부족·부분 거래는 별도 검증 |

- 위 계산은 현행 규칙의 결과를 확인한 것이며 생산 속도·승리 목표·웨이브 수를 변경하지 않습니다.
- 정제 시설2기는 생산량 기준의 최소 필요 수이며 충분한 승리 조건이 아닙니다. 건설·원석 공급·수출 재고·선박 출발을 함께 검증해야 합니다.
- 채취2기·정제2기의 건설비는 철80개+철판20개, 철판 원료까지 철100개분입니다. 기존 지급 설비를 유지하고 철거 환급을 사용하지 않는 준비 예시에서 탄약60개 생산까지 더하면 철105개분입니다. 초기 철100개와 후속 수입·방어 원료의 배분을 play-flow.md에 연결했습니다.
