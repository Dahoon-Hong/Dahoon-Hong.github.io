## 구현에 연결할 조건

- 승리 인정 조건의 시간 비교는 `출발 게임 시각 < 3900초`입니다. 정확히3900초를 허용하는 비교나 임의의 시간 여유를 넣지 않습니다. 정수 시간 단위·수치 정밀도는 기술설계에서 정합니다.
- 기한 이후의 선박 출발까지 시뮬레이션을 연장해 목표를 충족시키지 않습니다. 기한 시점 사건의 세부 표시·내역 처리는 승리 판정과 구분하며 늦은 수출을 승리로 바꾸지 않습니다.
- 치명 피해로 파괴한 시설을 같은 시점의 수리 대상 목록에서 유효하게 취급하지 않습니다. 자재가 이미 소비된 작업의 취소/소실 처리는 기존 실제 상태와 물자 보존 규칙에 연결합니다.
- 표적의 등장 순서는 실제 전투지역 진입점에서 유닛이 생성된 순서입니다. 지도 밖 시각 연출의 시작 시점을 사용하지 않습니다. 동시 등장까지 같은 최종 동률은 안정적인 식별 순서로 처리하는 기술설계안입니다.
- 취소/완공 동률에서는 해당 취소를 적용한 뒤 완공 사건의 대상 유효성을 확인합니다. 같은 현장을 완공시키고 동시에 회수물을 생성하는 중복 처리를 막습니다.
- 등장 대기 순서는 진입점별로 관리하는 기술설계안입니다. 한 진입점의 막힘을 이유로 다른 진입점까지 멈추지 않습니다. 이전 웨이브 적이 남았다는 이유로 다음 웨이브 시간표를 늦추지 않습니다.
- 위 규칙은 명시된 사건 사이의 우선순위입니다. 모든 공격·생산·운반·주문 사건의 전체 처리 순서가 확정됐다는 의미는 아닙니다.
