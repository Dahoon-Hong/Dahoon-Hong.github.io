# docs 작업 지침

- `docs/`에는 사용자가 작성을 요청하거나 내용과 방향을 승인한 가이드 및 지침만 작성한다.
- 검토 중인 제안, 승인되지 않은 규칙, 임시 결론, 추측한 요구사항을 확정된 가이드처럼 기록하지 않는다.
- 필수 정보가 부족하면 문서에 임의의 값을 채우지 말고 사용자 확인을 먼저 받는다.
- 가이드의 기술 계약은 현재 코드의 로더, 타입, 테스트를 근거로 작성한다. 계획 문서나 오래된 설명과 충돌하면 현재 구현을 우선하고 충돌 사실을 알린다.
- 동일한 지침을 여러 문서에 복제하지 않는다. 공통 규칙은 `docs/adding-content/README.md`, 종류별 규칙은 해당 세부 가이드 한 곳에서 관리한다.
- 가이드 작업은 사용자가 별도 plan으로 지정하지 않은 한 plan 구현으로 분류하지 않는다.
