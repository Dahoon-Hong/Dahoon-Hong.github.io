# 99. UI와 튜토리얼

## 현재 적용 계획

06.5에 통합된 재설계와 07단계 탱크 콘텐츠가 완료된 뒤 우측 업그레이드 패널을 구현한다.

- 기존 하단 전체 모듈 상점과 단일 `UPGRADE` 버튼은 제거한다.
- 우측 패널은 내장 시스템·전투 모듈 목록, 선택한 모듈의 중앙 루트 그래프, 비용·효과·상태를 표시한다.
- 한 분기 선택 뒤 형제와 하위 가지는 시각·입력 양쪽에서 비활성화한다.
- 빈 그리드에서 설치 가능한 전투 모듈만 표시하고, 비전투 시스템에는 설치 경로를 표시하지 않는다.
- 튜토리얼은 이동 → 전투 모듈 설치 → 업그레이드 분기 선택 → 일시정지 관리 순서로 갱신한다.

세부 구현·검증 순서는 [06.5 중간 구현 점검](06.5-mid-term-review.md)의 우측 패널 작업과 완료 기준을 따른다.

## 이전 계획(재설계 전)

> 아래 내용은 재설계 전 계획의 역사 기록이다. 현재 실행 시에는 06.5의 현재 적용 계획을 우선한다.

## 목표

현재 기능을 처음 플레이하는 사람이 설명 없이도 기본 루프를 이해하도록 HUD와 튜토리얼을 정리한다.

## 선행 조건

- 01~07 단계의 핵심 기능이 동작한다.

## 작업 대상

- `src/ui/HUDManager.ts`
- `src/core/InputManager.ts`
- `src/core/Game.ts`
- `index.html`
- 필요 시 새 UI 상태 파일

## 작업 순서

1. 상단 상태 표시줄, 중앙 전장, 우측 상단 모듈 패널, 하단 상점의 역할을 고정한다.
2. 자원·물질·탄약·나노 물질과 저장 한도를 읽기 쉽게 표시한다.
3. 설치 가능, 자원 부족, 점유 칸, 비활성 모듈을 색상과 문구로 구분한다.
4. 첫 실행 시 이동 → 모듈 선택 → 설치 → 업그레이드 → 웨이브 생존 순서의 짧은 튜토리얼을 제공한다.
5. 일시정지 중 가능한 행동과 불가능한 행동을 표시한다.
6. 승리·패배·재시작·다음 지역 이동의 버튼과 문구를 통일한다.
7. `plans/user_guide.md`의 안내와 실제 UI를 다시 대조한다.

## 완료 기준

- 첫 플레이어가 이동, 설치, 업그레이드, 일시정지를 안내만으로 수행할 수 있다.
- 모든 자원 표시가 실제 저장 상태와 일치한다.
- 클릭 실패 이유를 사용자가 알 수 있다.
- 화면 크기와 관계없이 HUD가 겹치지 않는다.
- 사용자 가이드의 조작 키와 화면 위치가 실제 게임과 같다.

## 검증

- 튜토리얼을 처음부터 끝까지 별도 지식 없이 진행한다.
- 자원 부족·빈 칸 아님·모듈 파괴 상태의 피드백을 확인한다.
- 1280x720 기준 화면과 브라우저 창 크기를 줄인 화면을 확인한다.
- 키보드만으로 이동·일시정지를 수행하고 마우스로 정비한다.
- `npm run build`
