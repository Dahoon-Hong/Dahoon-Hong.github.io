# 26.7 은하계 월드맵과 진행도 저장

## 목표

시작 메뉴의 `GAME START`에서 은하계형 월드맵으로 이동하고, 해금된 실제 지역 또는 좌하단 `terrain-test`를 선택해 새 전투를 시작한다. 실제 지역 클리어 진행도는 비동기 저장소 인터페이스 뒤의 localStorage에 저장한다.

## 구현 범위

### 월드맵 데이터

- 새 `world-map.json`에 node 순서, map ID, normalized position, 다음 map ID, test 여부를 둔다.
- 실제 지역은 다음 순서로 연결한다.
  1. `aurelia/landing-zone`
  2. `aurelia/relay-fields`
  3. `cinder/ash-basin`
  4. `cinder/core-ruins`
- 권장 node 위치는 각각 `(0.32, 0.66)`, `(0.47, 0.52)`, `(0.63, 0.39)`, `(0.78, 0.25)`다.
- `test/terrain-test`는 `(0.12, 0.80)`의 `test` node로 두고 실제 지역 chain에 포함하지 않는다.
- loader가 중복 ID, 없는 map/progression 참조, 실제 지역의 순환/단절, 범위 밖 위치를 검증한다.

### Galaxy 화면

- 새 `ui.galaxy-map` 배경 asset을 1280×720 Canvas 기준으로 등록한다.
- node 연결선과 `locked`, `available`, `cleared`, `test` 상태는 Canvas overlay로 그린다.
- 상태가 바뀌는 node와 text를 배경 이미지에 합성하지 않는다.
- pointer hitbox와 keyboard node 이동/Enter 선택을 제공한다.
- locked node 선택은 전투를 시작하지 않고 잠금 상태를 표시한다.
- Escape 또는 `BACK`은 시작 메뉴로 돌아간다.

### CampaignProgressStore

- Promise 기반 `CampaignProgressStore`를 추가한다.
  - `load(): Promise<CampaignProgress>`
  - `save(progress): Promise<void>`
- `CampaignProgress`는 `version: 1`과 `clearedMapIds`만 가진다.
- 현재 구현은 `LocalStorageCampaignProgressStore`다.
- key는 `platform-vehicle-defense.campaign-progress.v1`을 사용한다.
- 첫 실제 지역과 다음 해금 상태는 저장하지 않고 `world-map.json` chain에서 계산한다.
- 알 수 없는 ID, test map ID, 중복 ID는 load 결과에서 제거한다.
- 손상된 JSON이나 localStorage 접근 실패 시 빈 진행도의 memory fallback으로 실행한다.
- 저장 실패는 현재 세션의 해금을 되돌리지 않고 다음 save에서 전체 목록을 다시 쓴다.
- Steam 인증, cloud merge, 충돌 해결 코드는 추가하지 않는다.

### 지역 선택과 클리어

- `ProgressionManager` 또는 새 region selection 경계가 map ID로 실제 region/wave 정의를 선택하게 한다.
- node 선택 시 기존 전투 runtime을 정리하고 선택 map의 tank start, Camera bounds, terrain, wave, pickup 상태로 새 런을 만든다.
- 실제 지역 클리어 시 in-memory `clearedMapIds`를 갱신하고 save를 시도한 후 월드맵으로 돌아간다.
- `terrain-test` 클리어는 save를 호출하지 않고 월드맵으로 돌아간다.
- GAME OVER의 retry는 같은 map을 새 런으로 다시 시작하고, WORLD MAP action은 현재 런을 버리고 월드맵으로 돌아간다.
- 26.6의 GAME START 호환 callback을 `AppScreen.WORLD_MAP` 전환으로 교체한다.

### 테스트

- 첫 실행의 기본 해금 상태
- 실제 region chain의 단계별 해금
- test node 상시 해금과 save 제외
- 정상/손상/접근 실패 localStorage
- unknown/duplicate/test ID 정리
- save 실패 후 memory 진행 유지
- locked node 선택 거부
- map 선택 시 runtime 전체 reset
- 실제 clear → save → world map, test clear → world map

## 완료 기준

- GAME START가 은하계 월드맵을 연다.
- 첫 지역과 test map만 초기 선택 가능하다.
- 실제 지역 클리어마다 다음 node가 열리고 reload 후에도 유지된다.
- test map은 항상 열려 있고 캠페인 저장값을 바꾸지 않는다.
- 선택한 map ID의 terrain, Camera, wave가 새 런에 적용된다.
- 손상되거나 사용할 수 없는 localStorage 때문에 앱 시작이 막히지 않는다.
- `npm test`, `npm run qa:art`, `npm run build`가 성공한다.
