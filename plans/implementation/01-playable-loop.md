# 01. 플레이 가능한 게임 루프

## 목표

게임을 시작해 웨이브를 진행하고, 승리 또는 패배한 뒤 재시작할 수 있는 한 지역의 최소 루프를 완성한다.

## 선행 조건

- 기준선 코드가 빌드된다.
- 현재 이동, 적 생성, 발사체, 코어 피해가 유지된다.

## 작업 대상

- `src/core/Game.ts`
- `src/core/WaveManager.ts`
- `src/ui/HUDManager.ts`
- 필요 시 `index.html`

## 작업 순서

1. 프로토타입 지역의 총 웨이브 수를 설정값으로 분리한다. 초기값은 짧은 검증을 위해 3개로 둔다.
2. 마지막 웨이브의 모든 적이 제거되면 `VICTORY`로 전환한다.
3. `GAME_OVER`와 `VICTORY` 화면에 결과와 재시작 버튼을 공통으로 표시한다.
4. 일시정지 중에는 이동·생성·적·발사체·효과의 시간이 진행되지 않도록 유지한다.
5. HUD의 남은 적 수가 현재 웨이브의 미생성 적과 필드 적을 정확히 표시하도록 정리한다.
6. `Space`와 `P` 조작을 가이드와 일치시킨다. `ESC`는 별도 요구가 확정될 때까지 추가하지 않는다.

## 완료 기준

- 시작 후 3개 웨이브가 순서대로 진행된다.
- 마지막 적을 처치하면 승리 화면이 표시된다.
- 코어 HP가 0이 되면 패배 화면이 표시된다.
- 승리·패배 화면에서 재시작하면 새 지역이 정상적으로 시작된다.
- 일시정지 중에는 적이 움직이거나 자원이 증가하지 않는다.

## 검증

- 일반 적만 남긴 상태에서 마지막 웨이브 승리를 확인한다.
- 적을 코어에 도달시켜 패배를 확인한다.
- 플레이 중 일시정지 후 5초 이상 기다려 상태가 변하지 않는지 확인한다.
- 승리와 패배 후 각각 재시작한다.
- `npm run build`

## 다음 단계 조건

승리·패배·일시정지·재시작이 모두 안정적으로 동작해야 한다. 이 단계에서는 새 모듈 종류나 자원 종류를 추가하지 않는다.
