# 09. 밸런스와 배포 전 검증

## 현재 적용 계획

06.5에 통합된 재설계, 07단계 탱크 콘텐츠, 08단계 우측 패널이 완료된 뒤 새 구조를 기준으로 최종 검증한다.

- 비전투 시스템의 시작 활성화와 전투 모듈 전용 설치를 검증한다.
- 1x1·2x1·2x2 모듈의 경계·겹침·코어 칸 검사를 검증한다.
- JSON 업그레이드 비용, 효과 반영, 형제 분기 잠금, 재시작 초기화를 검증한다.
- 기존 생산·탄약·전투·일시정지·승패 흐름의 회귀를 검증한다.
- 상세 체크리스트는 [06.5 중간 구현 점검](06.5-mid-term-review.md)과 이 문서의 현재 검증 항목을 함께 사용한다.

## 이전 계획(재설계 전)

> 아래 내용은 재설계 전 계획의 역사 기록이다. 현재 실행 시에는 06.5의 현재 적용 계획을 우선한다.

## 목표

와이어프레임 버전을 다른 사람이 플레이해도 규칙을 이해하고, 주요 오류 없이 한 지역을 완료할 수 있는 상태로 만든다.

## 선행 조건

- 01~08 단계 완료

## 검증 범위

### 기능 회귀

- 게임 시작, 이동, 조준, 발사, 피격, 처치 보상
- 모듈 설치, 업그레이드, HP 0 비활성화
- 자원 생산, 변환, 저장, 탄약 소비
- 일시정지, 승리, 패배, 재시작, 지역 전환

### 밸런스

- 시작 자원으로 첫 방어 선택을 할 수 있는지
- 첫 웨이브에서 기본 모듈만으로 생존 가능한지
- 생산에 투자했을 때 전투력이 늦어지는지
- 탱커 등장 이후에도 대응 선택지가 있는지
- 탄약 부족과 저장 한도가 지나치게 자주 플레이를 막지 않는지

### 안정성

- 적·발사체·효과 배열 정리 중 오류가 없는지
- 코어 HP가 음수가 되지 않는지
- 처치 보상과 웨이브 카운트가 중복되지 않는지
- 창 크기, 일시정지, 빠른 연속 클릭에서 상태가 꼬이지 않는지

- 시스템 문서, 사용자 가이드, 실제 코드의 키·수치·규칙이 일치

## 배포 확인

2. 로컬 정적 서버에서 새로고침 후 게임 시작을 확인한다.
3. GitHub Pages 경로에서 Canvas와 모듈 스크립트가 정상 로드되는지 확인한다.
