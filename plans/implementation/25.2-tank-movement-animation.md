# 25.2 탱크 방향과 이동 애니메이션

## 목표

탱크가 마지막 이동 방향을 향하고, 이동 중 4컷 sprite animation을 재생하며, 화면에서 보이는 탱크 크기를 줄인다.

## 선행 조건

- [25.1 월드 확장과 카메라](25.1-world-expansion-camera.md)
- [Plan 25 설계 명세](../../docs/superpowers/specs/2026-09-06-plan-25-gameplay-expansion-design.md)

## 구현 범위

### Vehicle 상태

- 마지막 non-zero movement vector에서 facing angle을 계산한다.
- 정지해도 마지막 facing angle을 유지한다.
- 이동 중 animation timer/frame을 갱신한다.
- `prefers-reduced-motion`에서는 idle frame을 사용한다.
- cell size를 44px에서 약 36px로 조정한다.
- movement speed, weapon range, resource production 등 수치는 변경하지 않는다.

### 렌더링

- tank local grid, frame, module을 vehicle facing 기준으로 회전해 그린다.
- camera world-to-screen 변환 후 vehicle local rotation을 적용한다.
- module world center와 grid hit test가 동일한 cell size를 사용하도록 한다.
- 기존 fallback renderer에서도 sprite가 없을 때 방향/축소 상태가 보이게 한다.

### Sprite asset

- 4프레임 이동 sprite를 생성하거나 준비한다.
- `src/data/assets.json`에 tank movement asset을 등록한다.
- `AssetManager`의 기존 frame columns/duration 계약을 사용한다.
- asset이 늦게 로드되거나 실패해도 기존 tank fallback으로 게임을 계속할 수 있어야 한다.
- 필요 시 `qa-art`에 frame 수와 manifest 참조 검사를 추가한다.

## 변경 대상

- `src/entities/Vehicle.ts`
- `src/rendering/SpriteRenderer.ts`가 필요할 경우 frame/rotation 연결부
- `src/data/assets.json`
- `public/assets/game/tank/` 이동 sprite
- `docs/art-asset-provenance.md`에 생성 asset 기록

## 완료 기준

- 탱크가 이동 방향을 바라본다.
- 이동 중 4개 frame이 반복되고 정지 시 idle frame이 표시된다.
- reduced-motion 설정에서 animation이 정지한다.
- 현재보다 작은 탱크/grid가 camera 안에서 정상적으로 읽힌다.
- grid 설치 hitbox와 화면에 보이는 cell이 어긋나지 않는다.
- `npm run build`와 `npm run qa:art` 성공.

## 수동 QA

1. 상·하·좌·우 및 대각선 이동에서 facing을 확인한다.
2. 이동 시작/정지 시 frame 전환이 튀지 않는지 확인한다.
3. 탱크가 축소된 뒤 module label, grid, contact 영역이 겹치지 않는지 확인한다.
4. reduced-motion 환경에서 static frame과 이동 가능 여부를 확인한다.
