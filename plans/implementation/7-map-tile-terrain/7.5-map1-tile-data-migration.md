# 7.5 — 1번 맵 tile data migration

## 목표

7.2의 승인된 변환 결과를 `maps.json`의 canonical tile row로 반영하고, 기존 1번 맵의 polygon 지형을 제거한다.

## 구현 범위

- `aurelia/landing-zone.world`를 `18/160/120`으로 변경한다.
- `terrain.regions`를 제거하고 `terrain.legend`와 120개의 `terrain.rows`를 기록한다.
- 첨부 이미지 기준의 검정 영역을 `#`로, 나머지를 `.`로 저장한다.
- 빨강 marker 4개를 `enemySpawnCells`에 기록한다.
- 파랑 marker 1개를 `tankStartCell`에 기록한다.
- start/spawn cell이 `.`인지 확인하고, marker가 별도 terrain region으로 변하지 않도록 한다.
- 기존 map1의 progression/map ID/웨이브는 변경하지 않는다.
- 다른 네 맵의 cell size, rows/regions, 스폰 위치는 변경하지 않는다.

## 자동 검증

- `MapDefinitionLoader`가 map1을 로드한다.
- 모든 spawn에서 tank start까지 standard/tanker path가 존재한다.
- 초기 픽업 후보가 탱크가 접근할 수 있는 open component에 배치된다.
- map1의 모든 blocked cell이 대상별 collision 계약과 일치한다.
- map1 외 맵의 loader snapshot/기대 개수가 변하지 않는다.

## 수동 검토

- 160×120 rows를 grid preview로 펼쳐 첨부 이미지와 비교한다.
- 특히 네 빨강 marker 주변, 파랑 start 주변, 좁은 통로와 모서리를 확인한다.
- start/spawn 위치가 wall edge에 걸려 tank/enemy radius를 침범하지 않는지 확인한다.

## 완료 조건

1번 맵은 충돌 원본으로 polygon을 사용하지 않고, rows와 별도 위치 데이터만으로 동일한 시작/스폰/경로 결과를 낸다.
