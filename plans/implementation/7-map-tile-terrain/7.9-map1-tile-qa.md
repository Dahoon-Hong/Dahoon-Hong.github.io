# 7.9 — tile 전용 자동 QA와 debug overlay

## 목표

이미지와 tile data의 불일치, marker의 지형 겹침, 다른 맵 회귀를 실제 브라우저에 들어가기 전에 빠르게 검출한다.

## 구현 범위

- `scripts/qa-art.mjs`에 map1 rows/18px/artwork 검증을 추가한다.
- 필요 시 `scripts/qa-map1-tile.ps1` 또는 동일 목적의 기존 script에 다음 검사를 둔다.
  - rows dimensions
  - map world size
  - final PNG dimensions
  - start/spawn open-cell
  - spawn count 4/start count 1
  - source mapping metadata 존재
  - terrain output 재생성 가능 여부
- `F3` debug overlay를 map1에서도 사용할 수 있게 한다.
  - 18px grid
  - blocked cell tint
  - tank footprint
  - path waypoint
  - projectile hit cell
  - red spawn marker
  - hidden start cell은 debug에서만 표시
- overlay가 normal gameplay에서 기본 off인지 확인한다.
- error message에 map ID, row/column, marker index를 포함한다.

## 자동 검증 케이스

- row 개수가 120이 아니면 실패
- row 길이가 160이 아니면 실패
- 18px가 아닌 map1 cell size면 실패
- marker가 blocked면 실패
- final image size가 2880×2160이 아니면 실패
- map1에 regions가 남아 있으면 실패
- 다른 맵의 기존 regions/rows 계약이 예상과 다르면 실패
- image asset 누락 시 collision이 open fallback으로 변하지 않는지 확인
