# 7.8 — 1번 맵 gameplay 통합

## 목표

18px tile grid가 기존 탱크·적·투사체·자원 흐름을 바꾸지 않으면서, 1번 맵에서 실제 게임 규칙으로 적용되는지 확인한다.

## 검증 대상

### 탱크

- 파란 start cell center에서 시작한다.
- tank footprint가 `#` tile과 월드 경계를 통과하지 않는다.
- 직선 벽, 대각선 접근, 안쪽/바깥쪽 코너에서 관통·떨림·조기 정지가 없다.
- 벽면을 따라 이동하고 좁은 길에서 후진할 수 있다.
- 18px grid 전환이 차체 회전과 모듈 배치/사격각을 깨뜨리지 않는다.

### 적과 경로

- 네 red spawn cell에서 적이 순서대로 생성된다.
- spawn marker cell 자체는 적이 들어갈 수 있는 open cell이다.
- standard와 tanker 모두 `#`를 통과하지 않는다.
- 모든 spawn에서 tank start까지 유효한 경로가 있다.
- 대각선으로 지형 모서리를 비집고 지나가지 않는다.

### 투사체와 시야

- `#` 뒤의 적은 자동 조준 후보에서 제외된다.
- direct/arc projectile이 tile 경계를 관통하지 않고 첫 blocked tile에서 소멸한다.
- open tile을 지형으로 잘못 판정하지 않는다.

### 자원과 pause

- 초기 pickup이 탱크가 접근 가능한 open 공간에 생성된다.
- 적 drop이 blocked tile 위에 생성되지 않는다.
- PAUSED에서 이동·회전·전투·자동 생산·수집은 멈추고 기존 모듈 설치/업그레이드 규칙은 유지된다.

## 구현 범위

이 단계는 앞 단계에서 공통 API가 이미 cell size를 지원한다는 전제 아래, 필요한 최소 연결 수정만 포함한다. 웨이브 수치, enemy definition, progression은 변경하지 않는다.
