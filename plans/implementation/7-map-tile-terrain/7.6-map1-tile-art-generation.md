# 7.6 — tile data에서 1번 맵 이미지 생성

## 목표

1번 맵의 보이는 지형을 동일한 160×120 rows에서 생성해 collision tile과 이미지 경계를 일치시킨다. 지형은 runtime obstacle object가 아니라 최종 맵 이미지의 일부로 표현한다.

## 구현 범위

- `generate-campaign-terrain-maps.ps1`가 map1의 rows를 읽어 blocked tile을 그리도록 수정한다.
- map1은 polygon을 읽어 지형을 그리지 않는다.
- 18px tile 단위로 center/edge/corner 시각 변형을 선택할 수 있게 하되, 변형 선택은 인접 tile을 기준으로 한다.
- tile의 외곽 경계는 실제 collision cell 경계 안에 고정한다. 그림자·빛·균열이 open cell로 번져 통과 불가처럼 보이지 않게 한다.
- tile art는 generator에서 최종 `aurelia-landing-zone-map.png`로 합성한다. runtime에서 반복 장애물 sprite를 별도 entity처럼 그리지 않는다.
- 현재 map1의 장식용 `tile-variant-1` 반복 overlay가 실제 지형을 대신하지 않도록 제거하거나 map1에서 비활성화한다.
- 필요한 신규 terrain art asset은 `assets.json`에 등록하고, 사용하지 않는 기존 map1 terrain overlay 참조는 정리한다.
- source, 생성 script, output 크기와 제작 방법을 `docs/art-asset-provenance.md`에 기록한다.

## 정합성 검증

- output PNG logical/draw size가 `2880×2160`인지
- generator가 같은 rows로 다시 실행될 때 동일한 지형 경계를 만드는지
- 모든 `#` tile은 결과 이미지에서 terrain 색/텍스처를 가지는지
- 모든 `.` tile은 terrain fill이 아닌 ground를 유지하는지
- 경계선·shadow가 collision 경계를 2px 이상 벗어나지 않는지
- representative 직선 벽, 안쪽 코너, 바깥쪽 코너, 좁은 통로를 overlay로 확인하는지

## 검증 명령

```text
powershell -ExecutionPolicy Bypass -File scripts/generate-campaign-terrain-maps.ps1
npm run qa:art
npm run build
```

## 완료 조건

최종 맵 이미지와 rows를 겹쳐도 보이는 blocked terrain과 실제 blocked cell이 일치하며, 이미지 생성이 실패해도 runtime collision data가 open으로 변하지 않는다.
