# 7.7 — 1번 맵 스폰 marker와 시작점 표시 정책

## 목표

terrain과 spawn/start의 책임을 분리한다. 적 스폰은 플레이어가 알아볼 수 있게 표시하고, 탱크 시작점은 일반 게임 화면에서 표시하지 않는다.

## 구현 범위

- `Game.renderMap()` 이후 actor보다 낮은 ground/map layer에 map1 spawn marker를 그린다.
- marker 위치는 `TerrainGrid.cellToWorldCenter(enemySpawnCell)`에서만 계산한다.
- marker는 빨강 계열의 고정 ring/portal 형태로 표시하고, terrain collision 대상이 아니다.
- marker를 별도 적/장애물 entity로 만들지 않는다.
- `tankStartCell`은 normal render path에서 그리지 않는다.
- debug overlay에서만 start cell을 별도 색상으로 표시해 QA가 위치를 확인할 수 있게 한다.
- camera scroll과 viewport clipping을 적용해 화면 밖 marker는 그리지 않는다.
- map1 외 맵에는 이번 marker 정책을 적용하지 않거나 기존 표시를 유지한다.

## 테스트와 수동 확인

- spawn marker 중심이 `enemySpawnCell` 중심과 일치한다.
- marker가 있는 cell의 `enemy` collision은 open이다.
- normal gameplay 화면에 blue start marker가 나타나지 않는다.
- debug overlay에서 네 spawn과 한 start가 올바른 cell에 표시된다.
- marker가 적 생성 위치나 pathfinder 결과를 변경하지 않는다.
- 카메라를 이동해도 marker가 world 좌표에서 흔들리지 않는다.

## 검증 명령

```text
npm test
npm run build
```

이 단계의 최종 표시 확인은 7.10의 실제 브라우저 QA에서 수행한다.

## 완료 조건

사용자는 네 적 스폰 위치를 화면에서 식별할 수 있고, 탱크 시작 위치는 게임 시작 시 시각적으로 노출되지 않는다.
