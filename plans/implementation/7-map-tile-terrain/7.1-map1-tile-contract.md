# 7.1 — 1번 맵 tile 계약과 좌표계

## 목표

첨부 레이아웃을 1번 맵의 구현 가능한 tile 계약으로 고정한다. 이 단계에서는 기존 런타임 동작을 바꾸지 않고, 이후 단계가 같은 좌표·symbol·marker 의미를 사용하도록 경계를 정한다.

## 확정할 내용

- map ID: `aurelia/landing-zone`
- world size: `2880×2160px`
- cell size: `18px`
- grid: `160×120`
- terrain legend: `.` = `open`, `#` = `hill`
- `#`의 collision target: `tank`, `enemy`, `projectile` 모두 `true`
- 탱크 시작점: `tankStartCell` 하나, terrain이 아니며 일반 렌더링에서 숨김
- 적 스폰점: `enemySpawnCells` 네 개, terrain이 아니며 빨강 marker로 표시
- 첨부 이미지 source의 좌표를 월드로 옮길 때 uniform scale과 중앙 정렬 사용

## 구현 범위

- map1 전용 source image 이름과 보관 위치 확정
- image-to-world mapping의 source size, scale, offset 기록
- marker가 tile 경계를 가로지를 때 가장 가까운 유효 cell로 반올림하는 규칙 확정
- 시작점/스폰점이 open cell이어야 한다는 validation 조건 정의
- 1번 맵에서 `terrain.rows`와 `terrain.regions`를 함께 사용하지 않는 규칙을 테스트 목록에 추가

## 검증

- [ ] `160×120×18`이 `2880×2160`과 정확히 일치한다.
- [ ] 첨부 이미지의 빨강 marker 수가 4개, 파랑 marker 수가 1개인지 확인한다.
- [ ] 변환 전후 좌표가 월드 밖으로 나가지 않는다.
- [ ] marker cell의 center가 `#`가 되지 않는다.
- [ ] map1 외 맵의 cell size/terrain source를 변경하지 않는지 diff 범위를 확인한다.

## 완료 조건

이 단계에서 변환 규칙과 데이터 계약이 문서·테스트 이름으로 고정되어야 하며, 정확한 cell 좌표는 7.2의 변환 report와 7.5의 `maps.json`에서 확인할 수 있어야 한다.
