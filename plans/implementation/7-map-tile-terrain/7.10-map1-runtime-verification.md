# 7.10 — 1번 맵 실제 실행 검증

## 목표

문서·unit test·정적 QA로 확인할 수 없는 화면 정렬과 조작 감각을 실제 게임에서 검증한다. 기능 개발이므로 PR 전 `integration-tester` 결과가 PASS여야 한다.

## 실행 절차

1. 저장소 루트에서 `npm run dev`를 실행한다.
2. `integration-tester`(`.codex/agents/integration-tester.toml`)를 사용해 브라우저에서 첫 번째 맵만 선택한다.
3. debug overlay를 켜서 실제 map image, 18px grid, blocked cells, spawn/start marker를 겹쳐 확인한다.
4. 검증 결과와 재현 경로를 `docs/plan-7-verification.md`에 기록한다.

## 필수 시나리오

- 게임 시작 직후 탱크가 파란 위치에서 시작하고 blue marker는 보이지 않는다.
- 네 red spawn marker가 모두 보이며 marker가 벽/언덕처럼 충돌하지 않는다.
- 각 spawn에서 생성된 standard/tanker가 지형을 통과하지 않고 탱크를 향해 우회한다.
- 탱크로 넓은 길, 좁은 길, 직선 벽, 안쪽 코너, 바깥쪽 코너, 후진을 조작한다.
- 차체 회전 중 벽 관통, corner snag, 축 방향 편향, 화면 흔들림이 없다.
- 언덕 뒤 적을 자동 조준하지 않고, 발사된 탄환이 첫 blocked tile에서 멈춘다.
- 카메라를 월드 외곽까지 이동해 맵 이미지와 collision grid의 offset이 어긋나지 않는지 확인한다.
- 웨이브·자원·모듈 UI·pause 동작이 기존과 동일하다.
- 새로고침 후 첫 맵 선택과 campaign progression이 기존처럼 동작한다.
- 30초 이상 실행해 marker/terrain draw가 누적되거나 성능이 급락하지 않는지 확인한다.

## 실패 처리

- tile과 그림이 한 cell이라도 어긋나면 PASS로 기록하지 않는다.
- 서버 실행/브라우저 조작이 막히면 원인을 해결하거나 명확한 BLOCKED 결과를 남기고 PR을 만들지 않는다.
- 실제로 실행하지 않은 scenario는 통과로 기록하지 않는다.
