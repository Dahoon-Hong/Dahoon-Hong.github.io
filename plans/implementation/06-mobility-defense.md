# 06. 기동성과 방어

## 목표

탈것의 이동을 모듈 기반으로 만들고, 장갑판·모듈 HP·관통력을 연결한다.

## 선행 조건

- [02 모듈 기반 정리](02-module-foundation.md) 완료
- [03 전투 MVP](03-combat-mvp.md) 완료

## 작업 대상

- `src/entities/Vehicle.ts`
- `src/entities/Module.ts`
- `src/core/Game.ts`

## MVP 규칙

- `Power Pack`이 하나라도 활성 상태여야 차량이 이동한다. Power Pack이 없거나 파괴되면 이동 속도는 0이다.
- 활성 `Caterpillar Track`이 있으면 Power Pack의 이동 속도를 사용한다. 궤도가 없거나 파괴되면 이동 속도는 50%로 제한한다.
- Power Pack과 Caterpillar Track은 현재 8방향 자유 이동을 유지하며, 회전 물리는 보류한다.
- `Armor Plate`는 차량에 들어오는 피해를 먼저 받는 장갑 모듈이다. 기본 장갑 수치는 20, 자체 HP는 120이다.
- 피해 전달 순서는 `Armor Plate → 피격 모듈 → Core`로 구현한다. 장갑이 남아 있으면 피격 모듈을 보호하고, 장갑이 없거나 파괴되면 피격 방향의 외곽 격자 모듈이 피해를 받는다.
- 피격 방향은 코어에서 적 충돌 지점으로 향하는 벡터의 부호를 8방향 외곽 격자로 변환한다. 해당 위치가 비어 있거나 파괴된 경우 코어가 피해를 받는다.
- 유효 피해는 `max(0, 피해량 - max(0, 장갑 수치 - 관통력))`으로 계산한다. 장갑판은 유효 피해 계산 전 원래 피해량만큼 자체 HP를 잃는다.
- 장갑판이 파괴되면 더 이상 피해를 흡수하지 않는다. 관통력 기본값은 0이다.

## 작업 순서

1. 현재 직접 지정된 차량 속도를 Power Pack의 이동 성능으로 옮긴다.
2. 기본 이동은 8방향 자유 이동을 유지하고, 회전 물리 모델은 추가 요구가 있을 때까지 구현하지 않는다.
3. Caterpillar Track은 회전 속도·최대 속도 설정을 보유하며 초기에는 이동 속도 제한에만 사용한다.
4. Armor Plate 모듈을 설치하고 코어 보호와 자체 HP를 정의한다.
5. 피해 전달 순서 `장갑판 → 피격 모듈 → 코어`를 확정하고 구현한다.
6. 관통력과 장갑 수치의 최소 계산식을 추가한다.
7. 차량 방향에 따른 사격 각도는 차량 방향 모델이 확정된 뒤 연결한다. 피격 방향 기반 모듈 피해는 현재 구현에서 연결한다.

## 완료 기준

- 동력 장치의 상태에 따라 차량 이동 가능 여부와 속도가 바뀐다.
- 무한궤도 또는 기동 모듈이 파괴되면 정의된 이동 제한이 적용된다.
- 장갑판이 피해를 흡수하고 파괴되면 보호 효과가 사라진다.
- 관통력과 장갑의 상호작용이 차량에 들어오는 직접 피해에 동일하게 적용된다.
- 장갑판 처리 후 피격 방향의 모듈 HP가 감소하고, 모듈이 없거나 파괴되면 코어로 피해가 전달된다.

## 검증

- 기동 모듈을 비활성화해 이동 제한을 확인한다.
- 장갑판이 있는 경우와 없는 경우의 코어 피해를 비교한다.
- 장갑판 파괴 후 코어로 피해가 전달되는지 확인한다.
- 외곽 격자의 각 방향에서 해당 모듈만 피해를 받는지 확인한다.
- 피격 모듈이 파괴된 뒤 같은 방향의 피해가 코어로 전달되는지 확인한다.
- 관통력 0 및 장갑보다 큰 관통력에서 유효 피해를 확인한다.
- `npm run build`

## 구현 결과

- Power Pack과 Caterpillar Track을 추가하고, Power Pack 부재·파괴 시 정지 및 Track 부재·파괴 시 50% 속도 제한을 연결했다.
- 초기 차량에 Power Pack과 Caterpillar Track을 설치해 기존 8방향 이동을 유지했다.
- Armor Plate의 자체 HP, 장갑 수치, 관통력 계산을 구현하고 적 충돌 피해를 `Vehicle.takeDamage()` 경로로 통합했다.
- 충돌 방향을 외곽 격자 모듈로 변환해 `Armor Plate → 피격 모듈 → Core` 피해 전달과 모듈 파괴 후 코어 전환을 구현했다.
- HUD 상점에 Power Pack, Caterpillar Track, Armor Plate 설치 항목을 추가하고 2행 배치를 지원했다.
- 차량 방향 기반 사격각도와 회전 물리는 후속 범위로 남겼다.

## 다음 단계 조건

재설계 전환 메모: 재설계 이후 `Power Pack`, `Caterpillar Track`, `Armor Plate`는 설치 가능한 격자 모듈이 아니라 항상 활성화된 내장 시스템이다. 이동 속도와 장갑 수치는 유지하고 업그레이드 효과만 각 시스템 JSON의 선택지에서 적용한다. 내장 시스템은 1차 버전에서 개별 격자 피격·파괴 대상이 아니다.

이동·방어 규칙이 수치로 재현되고, 기동 모듈과 장갑판이 실제 플레이에서 의미 있는 선택이 되어야 한다.
