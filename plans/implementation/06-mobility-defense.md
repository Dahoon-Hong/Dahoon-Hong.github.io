# 06. 기동성과 방어

## 목표

탈것의 이동을 모듈 기반으로 만들고, 장갑판·모듈 HP·관통력을 연결한다.

## 선행 조건

- [02 모듈 기반 정리](02-module-foundation.md) 완료
- [03 전투 MVP](03-combat-mvp.md) 완료

## 작업 대상

- `src/entities/Vehicle.ts`
- `src/entities/Module.ts`
- `src/entities/Projectile.ts`
- `src/core/Game.ts`

## 작업 순서

1. 현재 직접 지정된 차량 속도를 동력 장치 모듈의 이동 성능으로 옮긴다.
2. 기본 이동은 8방향 자유 이동을 유지하고, 회전 물리 모델은 추가 요구가 있을 때까지 구현하지 않는다.
3. 무한궤도 모듈은 회전 속도·최대 속도 설정을 보유하며 초기에는 이동 속도 보정만 제공한다.
4. 장갑판 모듈을 설치하고 보호 영역과 자체 HP를 정의한다.
5. 피해 전달 순서를 `장갑판 → 보호 모듈 → 코어` 중 하나로 확정하고 구현한다.
6. 관통력과 장갑 수치의 최소 계산식을 추가한다.
7. 방향별 피해와 사격 각도는 차량 방향 모델이 확정된 뒤 연결한다.

## 완료 기준

- 동력 장치의 상태에 따라 차량 이동 가능 여부와 속도가 바뀐다.
- 무한궤도 또는 기동 모듈이 파괴되면 정의된 이동 제한이 적용된다.
- 장갑판이 피해를 흡수하고 파괴되면 보호 효과가 사라진다.
- 관통력과 장갑의 상호작용이 모든 직사 피해에 동일하게 적용된다.
- 코어 피해와 모듈 피해의 경로가 문서와 일치한다.

## 검증

- 기동 모듈을 비활성화해 이동 제한을 확인한다.
- 장갑판이 있는 경우와 없는 경우의 코어 피해를 비교한다.
- 장갑판 파괴 후 피해 전달 대상이 바뀌는지 확인한다.
- 폭발 피해가 장갑판 규칙을 따르는지 별도로 확인한다.
- `npm run build`
