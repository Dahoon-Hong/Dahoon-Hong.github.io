# 25.4 모듈 회전·드래그 배치·사격각

## 구현 범위

### Orientation-aware CombatGrid

- placement와 CombatModule에 `orientation: 0|1|2|3`을 저장한다.
- 90°/270°에서 width와 height를 교환한 footprint를 계산한다.
- `canInstall`, `install`, initial placement가 orientation을 검증한다.
- 기존 placement를 occupancy에서 안전하게 제거한 뒤 새 anchor/orientation을 검증하고 재등록한다.
- move/rotate 실패 시 occupancy, anchor, orientation, 구매 수량을 변경하지 않는다.
- 비전투 builtin module은 이동/회전 대상에서 제외한다.

### Pointer drag와 설치 ghost

- PAUSED 중 pointer down으로 module을 선택하고 drag를 시작한다.
- pointer move 시 screen 좌표를 camera로 world 좌표로 바꾼 뒤 grid anchor를 계산한다.
- drag 중 `R` keydown은 orientation을 시계방향으로 한 단계 바꾼다.
- 유효 ghost는 설치 가능 색, 무효 ghost는 위험 색과 footprint로 표시한다.
- pointer up에서 유효할 때만 placement를 커밋한다.
- 무효 drop은 원래 placement 또는 설치 대기 상태로 복귀한다.
- panel hitbox 입력은 world drag로 전파하지 않는다.

### 사격각 판정

- module definition의 `fireArcDegrees`를 읽는다.
- 실제 aim angle은 tank facing과 module local orientation을 합산한다.
- range 내 살아 있는 적을 angle difference로 필터링한다.
- 후보가 없으면 ammo spend, projectile spawn, cooldown start를 하지 않는다.
- 기존 direct/arc projectile 피해, 탄약, sound event 계약은 유지한다.

### 사격각 preview

- 설치 ghost와 선택/drag module에 방향 선을 그린다.
- module 중심에서 `fireArcDegrees / 2` 양쪽으로 부채꼴을 그린다.
- preview 계산과 combat target filter가 같은 helper를 사용한다.
- camera 이동, tank facing, module orientation을 모두 반영한다.

## 완료 기준

- 구매한 1x1/2x1 module을 ghost로 설치할 수 있다.
- 직사각형 module을 `R`로 회전하면 width/height와 표시 방향이 함께 바뀐다.
- 설치된 module을 PAUSED 중 drag로 다른 유효 cell로 옮길 수 있다.
- blocked/occupied/out-of-grid drop이 거부되고 기존 상태가 보존된다.
- module별 사격각이 다르게 적용되고 사격각 밖 적에게 발사하지 않는다.
- ghost와 선택 module의 preview가 실제 발사 방향과 일치한다.
- PAUSED 중 이동·적·발사체·자동 생산·수집은 멈춘다.
- `npm run build` 성공.

## 수동 QA

1. 빈 grid에 module ghost를 띄우고 footprint와 방향을 확인한다.
2. `R`을 반복 입력해 0/90/180/270° 순환과 시계방향 표시를 확인한다.
3. blocked, occupied, 경계 밖에 drop해 거부와 rollback을 확인한다.
4. 설치된 module을 drag하고 회전하면서 preview/occupancy를 확인한다.
5. 적을 사격각 안팎에 두고 발사 여부, ammo, cooldown을 확인한다.
6. pause 중 배치 작업만 진행되고 전투/생산/수집 시간이 진행되지 않는지 확인한다.
