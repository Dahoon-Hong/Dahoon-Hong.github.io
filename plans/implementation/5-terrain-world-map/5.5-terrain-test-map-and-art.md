## 구현 범위

### 테스트 지역 데이터

- `test/terrain-test` map ID와 progression region을 추가한다.
- progression entry에 `campaign: false` 또는 동등한 명시적 구분을 두고, 기존 순차 `ProgressionManager.advance()`가 test region을 방문하지 않게 한다.
- world는 36px cell의 80×60, 즉 2880×2160px로 만든다.
- 중앙 광장에 tank start cell을 둔다.
- 열린 외곽의 최소 세 방향에 고정 enemy spawn cell을 둔다.
- 다음 구역이 terrain row에서 명확히 구분되게 한다.
  - 탱크가 자유롭게 회전할 수 있는 넓은 광장
  - 현재 tank footprint가 통과 가능한 좁은 길 두 곳 이상
  - 세 갈래 이상의 교차로
  - 입구가 하나인 작은 막다른 길
  - 직선 벽, 안쪽/바깥쪽 모서리, 섬 형태 hill
  - hill 뒤 자동 조준과 projectile 차단을 재현할 수 있는 사선
- tank start와 모든 spawn 사이의 standard/tanker 경로를 validation으로 확인한다.

### 고정 웨이브

- Wave 1: standard 6, tanker 0
- Wave 2: standard 8, tanker 2
- Wave 3: standard 10, tanker 4
- spawn 위치는 random edge가 아니라 map의 목록을 정해진 순서로 순환한다.
- 마지막 웨이브 완료 시 일반 클리어 결과를 만들되 캠페인 진행도에는 기록하지 않는다.

### 지형 asset

- 기존 art 방향을 유지한 중립적인 테스트용 배경과 hill tile을 생성한다.
- 최소 asset ID는 다음과 같다.
  - `map.test.terrain-test.background`
  - `map.test.terrain-test.ground`
  - `map.test.terrain-test.hill-center`
  - `map.test.terrain-test.hill-edge`
  - `map.test.terrain-test.hill-corner`
  - `map.test.terrain-test.spawn-edge`
- asset은 36px terrain cell에 맞게 정규화한다.
- hill 이웃 관계로 edge/corner 회전을 선택하고 collision cell을 벗어난 장식을 최소화한다.
- 생성 source, prompt, crop/resize 기록을 `docs/art-asset-provenance.md`에 추가한다.
- `assets.json`과 `qa-art`가 크기, 경로, layer, 참조 누락을 검증하게 한다.

### Debug overlay

- 현재 map ID가 `test/terrain-test`일 때만 `F3` toggle을 허용한다.
- overlay에 terrain grid, 대상별 blocked cell, tank footprint, enemy path, 최근 projectile terrain hit을 표시한다.
- overlay는 screen/world camera 변환을 따르고 HUD 위에 그리지 않는다.
- map을 나가거나 restart하면 기본 off로 초기화한다.

### 단계 검증

- 이 단계에서는 loader와 renderer를 통해 test map 데이터와 asset을 검증한다.
- 일반 플레이 진입은 5.7 월드맵 node 연결 후 최종 확인한다.
- 임시 production 메뉴, 숨은 단축키, map ID query parameter는 추가하지 않는다.

## 완료 기준

- `test/terrain-test`가 typed map과 progression region으로 로드된다.
- 기존 실제 캠페인을 순차 진행해도 test region으로 자동 진입하지 않는다.
- 80×60 row, 시작/스폰 cell, 세 고정 웨이브가 validation을 통과한다.
- 여섯 지형 asset이 manifest에 등록되고 collision row와 시각 경계가 대응한다.
- `F3` overlay의 각 layer가 test map에서만 활성화된다.
- test map ID는 아직 캠페인 순서에 포함되지 않는다.
- `npm test`, `npm run qa:art`, `npm run build`가 성공한다.
