# 5.6 시작 메뉴와 설정

## 목표

앱 시작 시 전투를 자동 실행하지 않고 Canvas 시작 메뉴를 표시하며, 게임 시작·설정·종료 흐름과 전투 simulation의 생명주기를 분리한다.

## 선행 조건

- 현재 `Game`, `AudioManager`, `InputManager`, Canvas logical coordinate 흐름 확인
- [Plan 5 설계 명세](../../../docs/superpowers/specs/2026-09-07-plan-26-terrain-world-map-design.md)

## 구현 범위

### App screen 상태

- 전투 `GameState`와 별도로 `AppScreen`을 추가한다.
- 최소 상태는 `START_MENU`, `SETTINGS`, `WORLD_MAP`, `GAMEPLAY`다.
- 앱 초기 screen은 `START_MENU`다.
- `GAMEPLAY`가 아니면 enemy, projectile, pickup, resource production, Camera follow를 update하지 않는다.
- screen 전환 시 HUD의 drag/selection과 눌린 movement input을 정리한다.

### 시작 메뉴

- 1280×720 Canvas에 게임 title과 세 action을 표시한다.
  - `GAME START`
  - `SETTINGS`
  - `EXIT`
- pointer hitbox와 키보드 위/아래, Enter 선택을 모두 지원한다.
- `GAME START`는 `openWorldMap()` 경계를 호출한다. 5.7 연결 전에는 기존 첫 지역 시작 callback을 호환 경로로 유지하고, 5.7에서 callback 내용만 월드맵 전환으로 바꾼다.
- `EXIT`는 실행 중인 전투 상태와 audio를 초기화하고 시작 메뉴에 머문다.
- 브라우저의 `window.close()`는 호출하지 않는다.

### 설정 화면

- 음악 볼륨, 효과음 볼륨, 화면 효과 감소를 제공한다.
- 기존 음악 volume cycle 흐름을 설정 화면에서도 재사용한다.
- `AudioManager`에 SFX volume getter/setter 또는 동일한 최소 제어를 추가한다.
- 화면 효과 감소 초기값은 `prefers-reduced-motion`을 따르고, 현재 세션의 사용자 선택이 이를 덮어쓴다.
- `BACK`과 Escape는 시작 메뉴로 돌아간다.
- 설정값은 현재 앱 실행 동안만 유지하며 localStorage 저장은 추가하지 않는다.

### 렌더링과 입력

- 메뉴는 현재 Canvas와 `VisualTheme` 색상/간격을 재사용한다.
- 메뉴 hitbox는 screen 좌표만 사용하며 Camera 변환을 거치지 않는다.
- HUD와 combat pointer listener가 메뉴 click을 처리하지 않도록 active screen guard를 둔다.
- screen reader용 DOM overlay나 새 UI framework는 이번 범위에 추가하지 않는다. 키보드 focus 표시와 선택 상태를 Canvas에 명확히 그린다.

### 테스트

- 초기 screen과 update gating
- START_MENU ↔ SETTINGS 전환
- GAME START callback 1회 호출
- EXIT의 runtime/audio reset
- music/SFX/reduced-effects 설정 반영
- 메뉴 상태에서 combat input 무시

## 완료 기준

- 새로고침 후 시작 메뉴가 먼저 표시되고 전투 simulation이 돌지 않는다.
- 세 menu action이 pointer와 keyboard로 동작한다.
- 설정 변경이 즉시 audio와 reduced-effects 렌더링에 반영된다.
- EXIT가 탭을 닫으려 하지 않고 runtime을 정리한다.
- gameplay 진입 후 기존 HUD와 입력이 정상 동작한다.
- `npm test`와 `npm run build`가 성공한다.

## 수동 QA

1. 앱 로드 후 적이나 wave가 시작되지 않는지 확인한다.
2. pointer와 keyboard로 세 메뉴와 BACK을 순회한다.
3. 음악/SFX 0%, 중간, 최대 상태를 들어 확인한다.
4. 화면 효과 감소 on/off에서 tank animation과 effect가 즉시 바뀌는지 확인한다.
5. 메뉴에서 W/A/S/D를 누른 뒤 gameplay에 들어가도 입력이 stuck되지 않는지 확인한다.
