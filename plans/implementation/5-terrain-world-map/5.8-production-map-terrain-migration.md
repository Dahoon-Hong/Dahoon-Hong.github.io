# 5.8 실제 지역 지형 전환

## 목표

`terrain-test`에서 검증한 공통 계약을 기존 네 지역에 적용하고, 각 지역의 컨셉과 캠페인 난이도에 맞게 광장·길·협로·교차로·막다른 길과 언덕 밀도를 조정한다.

## 공통 전환 규칙

- 네 지역 모두 36px terrain grid와 map-defined start/spawn cell을 갖게 한다.
- 기존 all-open/decorative compatibility fallback 의존을 제거한다.
- main route의 열린 폭은 현재 3×3 tank footprint에 여유 한 cell씩을 더한 최소 5 cell로 둔다.
- 작은 막다른 길은 탱크가 완전히 들어가 회전하거나 후진할 공간을 제공한다.
- 모든 적 spawn에서 초기 tank start까지 standard와 tanker 경로가 존재해야 한다.
- 적의 유일 경로를 tank가 물리적으로 막아 영구 정체시키지 않도록 주요 spawn에는 두 개 이상의 연결 경로를 우선한다.
- 초기 pickup 열 곳을 시작점 주변의 접근 가능한 cell에 배치할 수 있어야 한다.
- 배경에 그려진 벽·언덕과 실제 terrain row가 모순되면 배경 또는 지형 asset을 교체한다.
- progression의 기존 wave 수와 전투 수치는 변경하지 않는다.

## 지역별 작업

### Aurelia / Landing Zone

- 가장 넓은 광장과 낮은 hill 밀도를 사용한다.
- 외곽 spawn에서 중앙으로 이어지는 넓은 길을 세 방향 이상 둔다.
- 작은 hill 섬으로 벽면 이동과 projectile cover를 소개한다.
- 막다른 길은 짧고 입구가 넓어 초반 함정이 되지 않게 한다.
- 기존 차가운 청회색 착륙지 분위기를 유지한다.

### Aurelia / Relay Fields

- 중계선과 구조물 방향을 따라 직선 길과 교차로를 강조한다.
- 중앙 이전과 이후에 선택 가능한 우회로를 둔다.
- Landing Zone보다 협로와 시야 차단 구간을 늘리되 최소 두 개의 main route를 유지한다.
- 기존 선형 장식이 통과 가능 길로 오인되지 않게 terrain edge를 명확히 한다.

### Cinder / Ash Basin

- 비대칭 hill 덩어리와 긴 우회로를 사용한다.
- 광장 크기를 줄이고 협로 진입 각도를 다양하게 한다.
- 교차로 하나와 작은 안전 pocket을 제공하되 spawn에서 core까지 단일 chokepoint만 남기지 않는다.
- 재와 균열 장식은 이동 가능 지면에 머물고 붉은 위험 색이 collision 의미를 덮지 않게 한다.

### Cinder / Core Ruins

- 네 지역 중 가장 높은 지형 밀도와 복수의 짧은 우회로를 사용한다.
- 폐허 사이에 제한적인 광장, 교차로, 막다른 숨숨길을 배치한다.
- tanker가 통과하지 못하는 의도치 않은 병목을 제거한다.
- 복잡한 배경에서도 hill edge와 projectile cover가 즉시 읽히게 한다.
- 난이도는 경로 밀도와 시야 차단으로 높이고 적 수치나 wave 구성은 바꾸지 않는다.

## 아트 전환

- 기존 background, tile, debris를 지역별로 실제 terrain row와 대조한다.
- 지면 분위기만 표현하는 asset은 재사용한다.
- 통과 불가 구조가 배경에 고정되어 collision과 맞지 않으면 해당 background를 다시 생성하거나 편집한다.
- 각 지역에 planet palette를 사용한 hill center/edge/corner asset을 제공한다.
- 새 asset은 `assets.json`과 provenance에 등록하고 `qa-art` 검사를 추가한다.
- 전경 actor와 projectile보다 낮은 대비, collision edge는 배경보다 높은 가독성을 유지한다.

## 지역별 검증 순서

각 지역을 다음 순서로 하나씩 완료하고 다음 지역으로 넘어간다.

1. terrain row와 start/spawn validation
2. standard/tanker 초기 path 검사
3. tank main route와 막다른 길 이동
4. projectile/line-of-sight cover 검사
5. 기존 전체 wave clear
6. background/terrain/actor 가독성 확인
7. `npm test`, `npm run qa:art`, `npm run build`

## 변경 대상

- `src/data/maps.json`

- 필요 시 `src/data/progression.json`의 spawn 참조

- map validation/path reachability test 데이터

## 완료 기준

- 네 실제 지역이 모두 explicit terrain row를 가지며 decorative fallback을 사용하지 않는다.
- 지역별 start와 모든 spawn이 standard/tanker 도달 가능성 검사를 통과한다.
- main route는 tank가 통과 가능하고 시각적 길과 충돌 데이터가 일치한다.
- 초반에서 후반으로 갈수록 지형 밀도와 시야 차단 복잡도가 증가한다.
- 기존 wave, 자원, 전투 모듈, 진행도 수치가 유지된다.
- 네 지역을 각각 정상 클리어할 수 있다.
- `npm test`, `npm run qa:art`, `npm run build`가 성공한다.

## 수동 QA

1. 월드맵에서 네 지역을 순서대로 선택해 start 위치와 Camera bounds를 확인한다.
2. 각 지역의 모든 main route와 막다른 길을 tank로 이동한다.
3. 각 spawn에서 standard/tanker가 막힘 없이 core에 접근하는지 확인한다.
4. region별 cover에서 자동 조준과 projectile 충돌을 확인한다.
5. 언덕 가장자리를 tank로 따라 이동하고 projectile을 발사해 보이는 경계와 실제 blocked cell이 어긋나지 않는지 확인한다.
6. 마지막 지역까지 clear하고 unlock 흐름이 유지되는지 확인한다.
