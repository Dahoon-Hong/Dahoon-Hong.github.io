## 자동 검증

### Terrain과 이동

- loader schema와 모든 map row/legend 참조
- world/cell 경계 변환
- tank world/terrain 충돌과 벽면 이동
- standard/tanker radius-aware A*
- 대각선 corner cutting 금지
- 모든 spawn → 초기 tank start 경로
- projectile 첫 terrain hit와 line-of-sight

### 화면과 저장

- 초기 START_MENU 상태와 simulation 정지
- SETTINGS와 START_MENU 왕복
- WORLD_MAP node 상태와 locked 선택 거부
- 실제 clear의 다음 node 해금
- test clear의 진행도 불변
- localStorage reload, 손상 JSON, 접근/save 실패
- retry, WORLD MAP, EXIT의 runtime reset

### 명령

- `npm test`
- `npm run qa:art`
- `npm run qa:audio`
- `npm run build`
- `npm run qa:release`
- `qa:release`가 아직 test를 포함하지 않으면 `npm test`를 첫 단계로 추가한다.

## 수동 통합 시나리오

### 첫 실행

1. localStorage의 Plan 5 진행도 key를 비운 테스트 환경에서 앱을 연다.
2. 시작 메뉴에서 전투가 진행되지 않는지 확인한다.
3. 음악, 효과음, 화면 효과 감소를 바꾼 뒤 BACK으로 돌아간다.
4. GAME START로 월드맵을 열어 첫 지역과 좌하단 test map만 활성인지 확인한다.

### Terrain test

1. `terrain-test`에 들어가 F3 overlay를 켠다.
2. 광장, 두 협로, 교차로, 막다른 길을 모두 주행한다.
3. tank wall sliding과 world boundary를 확인한다.
4. 세 wave에서 standard/tanker A*와 모서리 통과 금지를 확인한다.
5. 언덕 뒤 target 제외, direct/arc projectile hit, ammo/cooldown을 확인한다.
6. clear 후 월드맵에서 실제 두 번째 지역이 잠겨 있는지 확인한다.

### 캠페인

1. Landing Zone부터 Core Ruins까지 실제 네 지역을 순서대로 clear한다.
2. 각 clear 뒤 다음 node가 열리고 이전 node가 cleared로 표시되는지 확인한다.
3. 매 지역의 spawn, tank route, pickup 접근성, cover를 확인한다.
4. 중간에 reload해 해금 상태가 유지되는지 확인한다.
5. GAME OVER retry가 같은 region의 fresh run을 만들고 해금을 지우지 않는지 확인한다.
6. WORLD MAP과 EXIT가 적, 탄환, effect, audio, HUD drag 상태를 남기지 않는지 확인한다.

### Plan 4 회귀

- Camera follow와 map bounds clamp
- tank facing과 4-frame animation
- Armory 연구, 구매, 설치
- module drag/rotation과 fire arc preview
- PAUSED 중 전투, 생산, 수집 정지
- HUD screen 좌표와 world pointer 변환

## 성능과 가독성

- 최대 wave의 활성 적 수에서 pathfinding이 같은 frame에 몰리지 않는지 browser performance panel로 확인한다.
- Camera 이동 중 terrain tile seam과 반복 패턴이 두드러지지 않는지 확인한다.
- hill edge, tank, enemy, projectile, pickup의 실루엣 우선순위를 네 실제 지역에서 비교한다.
- 성능 문제가 재현되지 않으면 flow field, path cache, worker 같은 추가 최적화는 도입하지 않는다.

## 완료 기준

- 자동 검증 명령이 모두 성공한다.
- 시작 메뉴 → 월드맵 → test/실제 map → 결과 → 월드맵 흐름이 끊기지 않는다.
- test map과 네 실제 지역에서 tank, enemy, projectile가 hill을 통과하지 않는다.
- 실제 네 지역이 순차 해금되고 reload 후에도 유지된다.
- test map이 캠페인 진행도를 바꾸지 않는다.
- Plan 4의 Camera, animation, Armory, module placement/fire arc가 회귀하지 않는다.
- 최대 wave에서 반복 가능한 frame hitch나 적 정체가 없다.
- QA 결과가 verification 문서에 남는다.
