# 6. 맵 아트와 지형·탱크 상호작용

작성일: 2026-09-07

상태: 6.1~6.6 자동 및 부분 실제 플레이 검증 완료. 잔여 수동 범위는 검증 기록에 남긴다.

## 목표

벽·언덕·길을 하나의 완성 맵 이미지로 표현하고, 같은 좌표의 숨겨진 지형 윤곽으로 이동과 전투를 판정한다. 탱크는 회전한 차체까지 벽을 관통하지 않으며, 벽면 이동과 코너 회전을 부드럽게 처리한다.

데이터 계약, 판정 방식, 아트 제작 원칙과 검증 기준은 [맵 이미지·지형 경계·탱크 상호작용 설계 명세](../../../docs/superpowers/specs/2026-09-07-plan-27-map-art-and-terrain-interaction-design.md)를 따른다.

## 선행 조건과 실행 원칙

- [5. 지형·월드맵](../5-terrain-world-map/5-terrain-world-map.md)의 TerrainGrid, 적 경로, 탄환/LOS, 테스트 맵과 실제 지역을 기반으로 한다.
- 구현 직전에 차체 렌더링, 궤도 애니메이션과 vehicle-motion.json의 최신 변경을 확인한다.
- 6.1부터 6.6까지 순서대로 진행하고 단계별로 커밋한다.
- 단계에 해당하는 자동 검사와 개발 서버 확인을 수행한다. 문서 작성만으로 구현이나 검증을 완료 처리하지 않는다.
- 맵 이미지와 충돌 경계는 함께 수정하고 검증한다. 이미지에 맞지 않는 격자를 보이지 않게 숨기는 것으로 완료하지 않는다.

## 공통 완료 기준

- 보이는 벽은 막히고 열린 바닥에는 설명되지 않는 충돌이 없다.
- 차체 비관통, 부드러운 코너 이동, 공통 지형 판정과 기존 게임 흐름을 모두 검증한다.
- docs/plan-27-verification.md에 실행 명령, 실제 주행 범위, 대표 경계 화면과 발견한 문제를 기록한다.
