# 07. 진행과 콘텐츠

## 목표

한 지역의 반복 플레이를 넘어, 코어 레벨·격자 확장·적 구성·지역과 행성 진행을 추가한다.

## 선행 조건

- [01 플레이 가능한 게임 루프](01-playable-loop.md) 완료
- [02 모듈 기반 정리](02-module-foundation.md) 완료
- [05 생산과 물류](05-production-and-logistics.md) 완료

## 작업 대상

- `src/core/Game.ts`
- `src/core/WaveManager.ts`
- `src/entities/Vehicle.ts`
- `src/entities/Enemy.ts`
- 필요 시 새 진행 상태 파일

## 작업 순서

1. 코어 레벨업 조건과 비용을 정하고, 레벨별 사용 격자를 설정한다.
2. 3x3에서 5x5로 확장할 때 기존 모듈 위치가 보존되도록 한다.
3. 일반 적·탱커 적의 수치와 등장 시점을 설정 데이터로 분리한다.
4. 지역별 웨이브 수와 웨이브 증가 규칙을 설정한다.
5. 지역 클리어와 행성 클리어를 구분한다.
6. 같은 행성의 다음 소단원에서 유지되는 모듈·레벨·자원을 저장한다.
7. 새 행성 진입 시 유지 항목과 초기화 항목을 적용한다.
8. 저장이 필요해질 때까지 브라우저 영속 저장은 추가하지 않고, 우선 메모리 상태 전환으로 검증한다.

## 완료 기준

- 코어 레벨업으로 정해진 격자가 해금된다.
- 웨이브마다 적 구성과 수가 설정에 따라 달라진다.
- 지역 클리어 후 다음 지역으로 이동할 수 있다.
- 같은 행성 안에서 유지 규칙이 적용된다.
- 새 행성 시작 시 초기화 규칙이 적용된다.

## 검증

- 격자 확장 전·후 모듈 위치와 선택 상태를 확인한다.
- 일반 적과 탱커 적의 등장 규칙을 확인한다.
- 지역 종료 후 유지되는 항목을 확인한다.
- 새 행성 진입 후 초기화되는 항목을 확인한다.
- `npm run build`

## 다음 단계 조건

플레이어가 한 지역의 승패뿐 아니라 다음 지역으로 이어지는 진행을 이해할 수 있어야 한다. 저장 정책이 확정되기 전에는 복잡한 세이브 슬롯을 만들지 않는다.
