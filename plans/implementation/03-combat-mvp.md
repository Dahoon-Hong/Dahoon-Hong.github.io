# 03. 전투 MVP

## 목표

직사 무기와 곡사 무기가 공통 전투 규칙으로 적을 조준하고 피해를 주도록 만든다. 이 단계에서는 탄약을 무제한으로 두고 전투 판정 자체를 먼저 안정화한다.

## 선행 조건

- [02 모듈 기반 정리](02-module-foundation.md) 완료

## 작업 대상

- `src/entities/Module.ts`
- `src/entities/Projectile.ts`
- `src/entities/Enemy.ts`
- `src/core/Game.ts`

## 작업 순서

1. 무기 공통 설정을 사거리, 피해량, 발사 간격, 투사체 속도, 최대 비행 거리로 정리한다.
2. 직사 무기는 사거리 안의 가장 가까운 살아 있는 적을 조준한다.
3. 곡사 무기는 목표 지점에 포물선 발사체를 보내고 착탄 시 폭발한다.
4. 직사 발사체의 적중·소멸 규칙과 곡사 발사체의 범위·거리 감쇠 규칙을 고정한다.
5. 프레임 간 이동으로 적을 통과하는 발사체를 최소한의 충돌 보정으로 방지한다.
6. 비활성화된 무기는 조준과 발사를 하지 않는다.
7. 현재 구현되지 않은 관통력은 방어 단계까지 보류하고, 직사 발사체는 적중 1회 후 소멸시킨다.

## 완료 기준

- 직사 무기가 사거리 안의 가장 가까운 적을 자동 조준한다.
- 곡사 무기가 목표 지점에서 폭발하고 범위 내 적에게 피해를 준다.
- 두 무기 모두 비활성화 상태에서는 발사하지 않는다.
- 발사체가 사거리 또는 최대 비행 거리를 넘으면 정리된다.
- 적 HP가 0이 되면 처치 보상이 한 번만 지급된다.

## 검증

- 가까운 적과 먼 적을 동시에 두고 가까운 적을 우선하는지 확인한다.
- 곡사 폭발 중심과 가장자리에 적을 두고 피해 차이를 확인한다.
- 여러 발사체가 같은 적을 동시에 맞힐 때 중복 처치 보상이 없는지 확인한다.
- 모듈 HP를 0으로 만든 뒤 공격 중단을 확인한다.
- `npm run build`
