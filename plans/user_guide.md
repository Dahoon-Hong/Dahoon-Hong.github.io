# 사용자 가이드

## 0. 프롤로그

우주 문명은 외계 생명체와 전쟁 중이다. 적의 수가 너무 많아 전선을 유지하기 어려운 상황에서, 공격으로 초토화된 행성을 되찾는 임무가 시작된다.

플레이어는 특수부대 소속으로, 공수전차와 함께 행성에 궤도 강하를 수행한다. 행성에 남은 적을 토벌하고 행성 재건의 기초를 마련해야 한다.

- 행성 단위의 대단원으로 진행한다.
- 행성 내에서는 여러 소단원을 진행한다.
- 공수 작전의 특성상 새로운 행성에 진입할 때는 최소한의 무장으로 시작한다.
- 같은 행성 안에서는 이전 소단원에서 획득한 무장을 재활용할 수 있다.

## 1. 튜토리얼 목표

적들이 행성을 점령한 상태다. 공수전차를 움직여 적의 공격을 버티고, 모듈을 추가·강화해 모든 적을 제거한다.

## 2. 게임 화면

### 상단 상태 표시줄

- `CORE HP`: 공수전차 코어의 현재 체력과 최대 체력
- `Resource`: 현재 보유 자원
- `WAVE`: 현재 웨이브와 남은 적의 수
- 조작 안내: 이동 키와 일시정지 키

### 중앙 전장

- 중앙의 격자형 탈것이 공수전차다.
- 탈것의 가운데에는 코어가 있고, 주변 격자에 모듈을 배치한다.
- 화면 가장자리에서 적이 등장해 코어를 향해 이동한다.
- 적의 체력은 적 위에 표시되는 체력 바로 확인할 수 있다.

### 우측 상단 모듈 정보 패널

우측 `UPGRADE WEB` 패널에서 내장 시스템과 전투 모듈을 선택한다.

- 모든 내장 시스템은 게임 시작 시 활성화되어 있으며 별도 설치가 필요 없다.
- 중앙 `root`는 자동으로 선택된다. 선택 가능한 업그레이드 중 하나를 고르면 같은 분기의 나머지 선택지는 비활성화된다.
- 업그레이드 효과와 비용은 각 모듈 JSON에서 정의한다.
- 빈 전투 격자를 선택하면 패널에 설치 가능한 전투 모듈과 `size`, 비용이 표시된다.

### 전투 모듈 설치

전투 모듈만 탱크의 고유 격자에 설치할 수 있다. 설치 좌표는 모듈 footprint의 좌상단 anchor이며, 모든 점유 셀이 비어 있어야 한다.

- 현재 전투 모듈: 개틀링 건(`1x1`, 자원 30), 박격포 유탄(`2x1`, 자원 50)
- 코어 셀, 막힌 셀, 이미 점유된 셀에는 설치할 수 없다.
- 다중 셀 모듈은 하나의 모듈 인스턴스로 동작하고 footprint의 중앙에서 발사한다.

## 3. 기본 조작

- `WASD` 또는 방향키: 공수전차를 8방향으로 이동
- `Space` 또는 `P`: 일시정지 및 재개
- 마우스 클릭: 격자 선택, 모듈 설치, 모듈 업그레이드

일시정지 중에는 전차 이동, 적, 발사체, 자동 생산·수집·자원 변환이 멈춘다. 이때 전투 모듈 설치와 업그레이드를 진행할 수 있다.

## 4. 모듈과 자원

현재 프로토타입은 모든 내장 시스템과 직사 무기 1개가 활성화된 상태로 시작한다. 곡사 무기는 빈 전투 격자에서 설치한다.

- 자원 생산기는 일정 시간마다 자원을 생산한다.
- 자원 생산기는 1초마다 자원 10을 생산한다.
- 시작 시 차량 주변에 자원 10개 묶음 10개가 배치되고, 수집기가 이를 회수한다.
- Recycler, Arsenal, Composer, Rail, Power Pack, Caterpillar Track, Armor Plate는 내장 시스템으로 작동한다.
- 현재 1차 구현에서는 내장 시스템을 격자에서 개별 파괴하지 않으며, 업그레이드 효과로 기능을 변경한다.
- Armor Plate의 장갑 값은 충돌 피해에 공통 적용되고, 피해가 남으면 충돌 방향의 전투 모듈을 거쳐 코어로 전달된다.
- 직사 무기는 사거리 안의 가장 가까운 적에게 직선 발사체를 발사한다.
- 곡사 무기는 목표 지점에 포탄을 발사하고, 착탄 시 범위 피해를 준다.
- 자원은 전투 모듈 설치와 업그레이드에 사용한다.
- 모듈을 업그레이드하면 JSON에 정의된 효과가 적용되며, 선택한 분기의 형제 선택지는 다시 선택할 수 없다.
- 적을 처치하면 적 종류에 따른 자원을 보상으로 얻는다.

### 목표 시스템

완성 버전에서는 다음 자원 흐름을 사용한다.

`자원 → 재활용기 → 물질 → 무기고 → 탄약`

`물질 → 물질 합성기 → 나노 물질`

수집기는 적의 사체와 맵의 잔해에서 자원을 수집하고, 생산 모듈은 출력 버퍼를 거쳐 Rail로 저장고에 전달한다. 현재 구현의 변환 흐름은 `resource → matter → ammo`와 `matter → nano`이며, 각 시스템의 수치와 업그레이드는 JSON에서 관리한다.

## 5. 웨이브와 승패

- 적은 화면 바깥에서 등장해 코어를 향해 이동한다.
- 웨이브마다 정해진 수의 적이 순서대로 등장한다.
- 일반 적은 빠르고 체력이 낮다.
- 탱커 적은 느리지만 체력이 높고, 2웨이브부터 등장할 수 있다.
- 적이 코어에 도달하면 코어가 피해를 받고 적은 사라진다.
- 코어 체력이 0이 되면 `GAME OVER`가 된다.
- 모든 웨이브의 적을 제거하면 지역을 클리어한다.

## 6. 구현 전 보강이 필요한 사항

다음 규칙은 플레이 경험이 흔들리지 않도록 구현 전에 확정한다.

1. **튜토리얼 범위**: 첫 플레이에서 안내할 조작, 설치, 업그레이드 단계와 완료 조건
2. **화면 배치**: 현재 프로토타입의 HUD 위치를 유지할지, 최종 UI에서 변경할지
3. **자원 명칭과 흐름**: 원자원·물질·탄약·나노 물질의 종류, 변환 비율, 생산 시간, 저장 한도
4. **탄약 규칙**: 탄약 부족 시 공격 중단 여부와 무기별 탄약 소비량
5. **행성 진행**: 소단원 종료 시 모듈을 유지하는 범위와 새 행성 시작 시 초기화되는 항목
6. **승리 조건**: 마지막 웨이브의 수, 웨이브 증가 규칙, 지역 클리어와 행성 클리어의 차이
7. **피해와 복구**: 코어·모듈의 피해량, 수리·교체 방법, 게임 오버 후 재시작 규칙
8. **모듈 배치**: 설치 가능한 격자, 모듈 방향, 철거·이동 가능 여부, 코어 레벨에 따른 확장 조건

> 참고: 현재 프로토타입은 재시작하면 코어·모듈·자원이 초기 상태로 돌아가며, 행성 간 진행 보존은 아직 구현되지 않았다.
