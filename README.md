# Project C

This is the clean Project C baseline on the parentless `defence_c` branch.
It contains a standalone Unity 3D URP project, the complete local Q-494 Notion
handoff snapshot and UI wireframe, and a newly numbered MVP implementation plan.

The Project C branch files are the working source for future development. Start
with [Project C instructions](AGENTS.md), then read the
[handoff index](ProjectC/Documentation/Notion-Q-494/INDEX.md) and
[Plan 1](plans/implementation/1-project-c-mvp/1-project-c-mvp.md).

This branch has no inherited game source or implementation plans. The Notion
source snapshot preserves planning history as reference material; it is not a
replacement for the new implementation plan.

## Open the Unity project

Open `ProjectC` from Unity Hub with Unity Editor `6000.2.14f1`, or use the Unity
CLI documented in [ProjectC/README.md](ProjectC/README.md). The project targets
Windows x64 and offline play.
